# Ep 0b — Notes

## Verified on this machine
- Windows 10 Pro, Python 3.12.10, git 2.50.0.windows.1, VS Code 1.135, Node 22.17 (unused).
- `py -m venv .venv` + `.venv\Scripts\activate` — works.

## Gotchas to show on camera (all in commands.md troubleshooting table)
- Missing "Add python.exe to PATH" tick on Windows — the single most common failure.
- PowerShell execution policy blocking `activate`.
- Debian/Ubuntu needing `python3.12-venv` as a separate package.
- Windows `python` opening the Microsoft Store instead of Python.

## Recording notes
- Tell experienced viewers to skip to ep 1 in the first 15 seconds.
- Don't detour into VS Code themes/extensions. Install, move on.
- Postgres and Node are explicitly NOT installed. Say why — it stops people quitting at setup.
